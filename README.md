# 框框看升学 · 高考升学直播知识库

> 一个专注于高考升学规划的直播平台知识沉淀仓库。
> 目标：帮考生和家长「按分数选科、分档推荐院校专业」，少走弯路。

## 平台定位

「框框看升学」以**视频号直播连麦答疑**为核心，沉淀了一套系统化的高报（高考志愿填报）知识体系：

- **883 个官方专业**完整稿
- **60 个高报生涯母题**
- **深度资料 167 份** + **方法推导 716 条**
- **专业分场景脚本 2649 份**
- **历史内容 370 篇** + **视频号直播 13 场**

## 核心方法论

直播与内容都遵循一套「框框方法」，结构化输出：

```
主题结论 → 数据/名单支撑 → 分段位建议 → 强基/路径补充
```

关键判断原则（来自平台直播观点）：

1. **高薪多集中于新工科**——计算机、自动化、电子信息等交叉学科。
2. **化生类需升学**——化学、生物类专业本科就业有限，建议读研。
3. **生医工需地域规划**——生物医学工程等专业要看地域产业配套。
4. **平台不承诺录取概率与就业**——只提供客观信息与路径分析，不误导。
